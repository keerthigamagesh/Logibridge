# Logibridge
Edge AI-based cold-chain monitoring system for pharmaceutical logistics using MQTT, TensorFlow Lite, Docker, and MLOps

## Technologies

- Python 3.11
- MQTT (Mosquitto)
- TensorFlow Lite
- Docker
- NumPy
- Scikit-learn
- TensorFlow
- Ansible

## Repository Structure

- scenario_architecture
- hardware
- data_pipeline
- training
- inference
- monitoring
- deployment
- optimisation
- reports

## Project Objective

Develop an Edge AI pipeline capable of monitoring refrigerated pharmaceutical trucks, detecting anomalies locally, and supporting scalable deployment through Edge MLOps.
